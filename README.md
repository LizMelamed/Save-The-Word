# Save The Word

Save The Word is a research-inspired reading game that helps children build faster, more confident reading. The project focuses on reading speed because slow and effortful reading increases cognitive load, reduces comprehension, and lowers engagement. The game uses mouse-based finger tracking as an external pacing mechanism to guide steady, forward reading. Stories are personalized by age and interests and the difficulty adapts over time based on performance. Later stages use fading text to encourage smoother reading while letting children keep words visible by reaching them.


## Features
- Adaptive stories generated by AI, themed by child interests
- Mouse-based finger tracking to guide reading pace
- Fading text mechanic to encourage fluent, forward reading
- Comprehension questions after each story
- Assessment + game rounds with progress tracking (3 reading rounds + mini-game + final challenge)
- Parent report and CSV export (PoC password: `1234`)

## Quick Start

### Backend
```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Environment
Create `backend/.env` and fill:
```
OPENAI_API_KEY=...
GEMINI_API_KEY=...
```

For the frontend, set this when deploying:
```
VITE_API_BASE_URL=https://your-backend-url
```

## API Endpoints
- `/generate-story`
- `/predict-reading-skill`
- `/log-session`

## Deployment
Recommended:
- Backend on Render
- Frontend on Vercel

Set CORS on the backend to allow your Vercel domain.
